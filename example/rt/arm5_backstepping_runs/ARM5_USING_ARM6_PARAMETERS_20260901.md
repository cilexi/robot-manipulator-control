# 第六关节参数用于第五关节的对比实验

实验目录：`20260901_193947`

本次将第六关节备份中的主要调参值用于第五关节：

- `k1_5 = 62`
- `k2_5 = 50`
- `nominal_inertia5 = 0.135`
- `gamma_theta = 1.5`
- `sigma_theta = 1.8`
- `alpha_limit5 = 3.3 rad/s`
- `virtual_accel_limit5 = 28 rad/s^2`

为保护第五关节，力矩硬限制没有照搬关节 6 的 `1.3 Nm`，而是保持
`tau_limit5 = 1.0 Nm`；其他第五关节速度、位移和障碍停机条件保持不变。
实验缩短为单周期（总时长 15 秒）。

## 结果

- 累积绝对误差：`0.0184012536 rad·s`
- RMS 跟踪误差：`0.0014085497 rad`
- 峰值跟踪误差：`0.0044929789 rad`
- 峰值实际命令力矩：`0.964350 Nm`
- 力矩速率限制比例：`4.3333%`
- 虚拟加速度未饱和
- 实验正常完成，未触发速度、位移或障碍保护

相同单周期条件下，第五关节推荐参数实验 `20260901_170643` 的累积绝对误差为
`0.0068184259 rad·s`。关节 6 参数在第五关节上的累积误差约为推荐参数的
`2.70` 倍；第五关节推荐参数相对减少约 `62.95%`。

本次命令行参数只用于该实验，没有覆盖 `nomal_backstepping.py` 和
`nomal_backstepping.cfg` 中已保存的第五关节推荐默认值。
